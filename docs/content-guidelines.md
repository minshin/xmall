# 商品页内容规范

xmall 是 SEO / GEO 网站，内容的质量和数量是生命线。每个机型页按以下固定结构写，读者设定为“不太懂 IT 的总务担当”。

## 页面结构（顺序固定）

1. **标题**：`{机型名}（{芯片/世代}）` + 副标题“レンタル・購入の価格比較と、はじめての方向けの詳しい解説”
2. **价格比较**：租（各租赁公司）／买（各商店）切换；“買う vs 借りる”计算器
3. **ひとことで言うと**：3–4 句。必须写出“适合谁”“不适合谁（以及替代机型）”
4. **スペックをやさしく解説**：每项规格三列——项目／官方规格／「つまりどういうこと？」。比喻优先（内存＝作業机の広さ，存储＝引き出し）
5. **使い方の例**：3–4 个场景，每个附推荐配置
6. **構成の選び方**：内存、存储各一段，最后给“迷ったら”结论
7. **よくある質問**：6–10 问。必含：Office 能否使用、Windows 系统兼容、内存是否够、买还是租、故障处理、归还时数据
8. **口コミ**：区分レンタル利用者／購入者
9. **よく比較される機種**：3 个，写清差异

## 事实规则

- 规格与官方价格必须来自厂商官网或可靠报道，并登记在 `sources`（URL + 访问日期）。
- 不确定的数字不写；改写为“公式仕様をご確認ください”。
- 税务、法律相关只写一般性说明，并提示咨询税理士等专业人士。
- 价格写明时点（例：2025年10月発表時点）。

## 生产流程

1. AI 起草（规格白话、场景、FAQ）
2. 人工核对事实与出处 → 填 `sources`
3. 日语母语者校对语气
4. 发布后按搜索词表现每季度更新 FAQ

## ステマ規制

- 联盟链接区域显示“広告・アフィリエイトリンクを含みます”。
- 合作方委托或有赠品的口碑必须显示标识。
