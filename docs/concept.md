# 产品概念

## 定位

xmall.jp ＝ 日本法人 IT 设备的 **租赁＋购买比价站**（类似价格.com，但垂直于 IT 设备，并且租和买都比）。

- 各家租赁公司只做服务，但都需要流量。xmall 用 SEO / GEO 把流量集中过来，再分给它们。
- 服务（审核、签约、配送、维修、回收）由合作方提供。xmall 只要 **流量和品牌**。

## 用户与场景

- 中小企业的总务 / 情シス（多为兼任，不太懂 IT）
- 新员工入职、短期项目、设计/开发用高性能机、在日本新设法人的外资企业（中日韩三语是差异点）

## 收入

| 来源 | 方式 | 备注 |
| --- | --- | --- |
| 租赁 | 向租赁公司按咨询/成交收费（CPA），后期改为租金分成 | 主收入，单价高 |
| 购买 | Amazon アソシエイト、楽天、厂商直营（バリューコマース・A8 等）联盟佣金 | 单价低、流量大，补全比价 |
| 其他 | 推荐位、价格指数等数据产品 | 后期 |

## 差异化

1. **标准目录**：SPU（机型）× SKU（规格 × 成色等级），软件做成“配置模板”叠加。各家按同一标准报价，才能真正比较。
2. **成色等级 S/A/B/C**：可检验的定义（外观、电池健康度、保修），抽检 + 口碑约束。
3. **租买并排 + 计算器**：“买还是租哪个划算”。
4. **详尽内容**：规格白话解说、使用场景、配置选法、FAQ —— 写给不懂 IT 的人。
5. **口碑**：只有经 xmall 租/买的人能打分；提问对所有人开放。
6. **MCP**：AI 助手可以直接在 xmall 上检索、比较、提交咨询。

## 冷启动

1. 先用公开信息把主力机型（约 30–50 个 SPU）的内容做扎实，打 SEO 底子。
2. 购买比价用联盟链接立刻可以变现。
3. 拿着流量和演示，去谈中型租赁公司入驻（第一批候选见 `docs/partners.md`，待补）。
